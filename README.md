# 静态博客

静态博客使用 11ty Static Site Generator 和 Netlify 建立。

- [11ty](https://www.11ty.io/) 静态文件生成器
- [Nunjucks](https://mozilla.github.io/nunjucks/) 模板引擎
- [moment.js](https://momentjs.com/)日期格式化
- [prism](https://prismjs.com/) 语法高亮
- [PostCSS](https://postcss.org/)
